Ajouter un article

Remplissez le formulaire, vérifiez l’aperçu, puis suivez les deux étapes tout en bas. Rien n’est publié tant que vous n’avez pas validé sur GitHub.

Cliquez ici, puis collez votre texte copié depuis Word (Ctrl+V ou Cmd+V).

Intertitres : ## Titre · gras : **mot** · italique : *mot* · lien : [texte](https://…) · image : ![description](images/nom.jpg) · citation : > texte · liste : - élément · note : [^1] dans le texte, puis [^1]: texte de la note en fin de document.

Aperçu

    Étape 1 — Créer le fichier de l’article

    Sur GitHub : dépôt → Add file → Create new file. Copiez le nom ci-dessous dans le champ du nom, collez le contenu dans la zone de texte, puis Commit changes.

    Étape 2 — Mettre à jour la liste des articles

    Sur GitHub : ouvrez articles.json, cliquez sur le crayon (Edit), sélectionnez tout, collez ce texte à la place, puis Commit changes.

    Le site se met à jour environ une minute après la validation.
